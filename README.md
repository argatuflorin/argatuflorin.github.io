## Update the homepage

Upload the contents of this package to the root of argatuflorin.github.io, then commit to main.
GitHub Pages uses main and / (root).

Public repositories are retrieved from the GitHub API on page load. A browser cache is used for 30 minutes. Refresh list forces a new check. If GitHub is unavailable or rate-limited, the saved list remains visible. No authentication token is required or embedded. Only public repositories are listed; this homepage repository is excluded from its own project cards.

Edit index.html for the presentation and GitHub descriptions for newly added repositories. The initial saved records are in repos-snapshot.json and embedded in github-projects.js. The existing 3D/time/frequency signal animation is retained in hero-signal.js.
