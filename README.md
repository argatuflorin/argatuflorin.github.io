# Florin-Ciprian Argatu — Academic website

Static website for GitHub Pages. Open index.html to preview it locally.

## Public pages

Overview, Research, Publications, Teaching, About, Contact and a printable academic CV.

## Publish

1. Extract the ZIP on your computer.
2. Open the argatuflorin.github.io repository, then Add file > Upload files.
3. Drag the CONTENTS of the extracted folder, including assets, into the upload area. Do not upload the ZIP or its parent folder.
4. Commit changes to main. GitHub Pages must use main and / (root).
5. Visit https://argatuflorin.github.io/ after deployment completes.
