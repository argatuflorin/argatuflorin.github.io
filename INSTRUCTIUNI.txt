PAGINA PRINCIPALA GITHUB

1. Dezarhivează acest pachet.
2. Deschide https://github.com/argatuflorin/argatuflorin.github.io
3. Add file > Upload files.
4. Încarcă toate fișierele și folderul assets din pachetul extras, direct în rădăcina depozitului. Nu încărca ZIP-ul sau folderul exterior.
5. Commit changes pe main.
6. După publicare, deschide https://argatuflorin.github.io/ și apasă Ctrl+F5.

Aceasta este pagina principală. Profilul academic rămâne în depozitul academic-website, iar laboratorul în MDoEE. Nu încărca acest pachet în academic-website.

Lista proiectelor publice se actualizează din GitHub la deschiderea paginii. Browserul poate păstra lista 30 de minute; butonul Actualizează lista forțează o verificare nouă. Dacă GitHub nu răspunde, sunt afișate proiectele salvate.
